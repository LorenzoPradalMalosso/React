# Exercício 8 — Teste de reprodução

## Roteiro de reprodução

1. Abrir a pasta `todo-pro`.
2. Executar `npm install`.
3. Executar `npm run dev`.
4. Abrir no navegador o endereço informado pelo Vite.

## Melhoria registrada

As instruções de execução foram centralizadas no README principal e na resposta do Exercício 3. A página inicial também foi substituída pela tela To-Do Pro, de modo que o resultado esperado fica claro logo após iniciar o servidor.
