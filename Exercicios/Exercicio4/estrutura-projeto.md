# Exercício 4 — Exploração orientada

1. O arquivo que contém os scripts do npm é o `package.json`.
2. A pasta `node_modules` não deve ser enviada ao Git porque suas dependências podem ser recriadas com `npm install` a partir do `package.json` e do `package-lock.json`.
3. O código principal da aplicação fica na pasta `src`.
4. O `main.jsx` é o ponto de entrada que cria a raiz do React e renderiza o componente `App` no elemento da página.
5. O comando que cria uma versão de produção é `npm run build`.
