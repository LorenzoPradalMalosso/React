# Exercício 3 — Primeiro projeto

O projeto foi criado com Vite e está disponível em [todo-pro](../../todo-pro/).

## Execução

```bash
cd todo-pro
npm install
npm run dev
```

O endereço exibido pelo Vite deve ser aberto no navegador. Para encerrar o servidor, use `Ctrl + C` no terminal.

## Entrega

- O projeto possui React, Vite e ESLint configurados.
- A tela foi alterada e agora apresenta a aplicação To-Do Pro.
- A execução e a finalização do servidor são feitas pelos comandos descritos acima.
